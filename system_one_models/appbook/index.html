    How Voyage usage and costs are calculated

    The server uses VOYAGE_API_KEY from its local environment. Calls stop with an error when credentials are absent. Embeddings use voyage-4; the dedicated reranker uses rerank-2.5.

    At the saved September 25 rates: embedding tokens × $0.06 / 1,000,000; reranking tokens × $0.05 / 1,000,000. Reranking usage already includes the query repeated for each candidate. We use the API’s usage.total_tokens, not a character-based estimate.

    These are list-price estimates, not invoices. Credits, negotiated rates, tax and local compute are separate. The saved ledger records the model and price applied to every call. Voyage pricing ↗
